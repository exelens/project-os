# Security

Project OS — kit методологии, не сервис. Пользовательских данных и prod-секретов в этом репозитории нет.

Находка в kit (скрипт apply, шаблон, который тащит секрет в продукт): GitHub Security Advisory или issue **без** живых секретов и без эксплойта чужого продукта.

Политика продукта, куда ложится scaffold, — корневой `SECURITY.md` после apply ([scaffold/SECURITY.md](scaffold/SECURITY.md)). Этот файл её не заменяет.
