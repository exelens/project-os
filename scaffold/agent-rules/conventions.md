# Конвенции агента (стеко-нейтральные)

1. **Канон > чат.** Правда в коде и коротких docs; чат не SSOT.
2. **Один owner на понятие.** Сначала таблица canon-owners, потом правка.
3. **Малый diff.** Не рефакторить соседнее «заодно»; не плодить файлы без нужды.
4. **Тест рядом с риском.** Нет теста — добавь тонкий; не раздувай suite близнецами.
5. **Evidence.** «Готово» только после команды проверки или честного «не прогнал, потому что…».
6. **Секреты.** Не коммить `.env`, токены, дампы prod.
7. **Время.** Единый helper / TZ-политика репо — не deprecated API наугад.
8. **DB sessions.** Не открывать вторую сессию, если caller передал существующую.
9. **Ошибки.** Клиенту — безопасное сообщение; в лог — `exception` / `exc_info`.
10. **Prism.** Audit/merge/verify не меняют код; wipe reviews — только человек.
11. **Post-code loop.** После любой задачи: (a) покрыть затронутый контур тестами, (b) актуализировать docs, (c) re-run тесты на актуальность. Три шага — один чат, не три разных сессии.
12. **Vibe-check (по желанию).** После задачи: спросить «какие скрытые риски, вопросы, предложения?» — агент анализирует diff и предлагает доп. шаги.
