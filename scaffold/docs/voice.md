## Правила написания

1. **Без эха** — не одно и то же слово в hero и подзаголовке подряд.
2. **Императив один раз** — либо headline, либо CTA; не в каждой строке.
3. **Тиры не смешивать** — лимиты и «полный X» только для той аудитории, которой положено.
4. **Глубина** — «до N», не «от огромного числа» рядом с реальным потолком плана.
5. **Кнопки** — глагол результата, не канцелярит.
6. **Ошибки API** — короткий `detail` / allowlist MSG, не стек и не сырой HTTP status text.
7. **Empty / loading** — не flash «пусто» до ответа API (`loading` до первого fetch / гидрации данных).
8. **Ачивки / бейджи** — не выдавать пачкой при первом пустом успехе (0 прогресса / 0 XP / пустой streak).
9. **Без ведущих emoji** в title / teaser primary UI, если продукт так решил; SSOT strip — TODO_EMOJI_STRIP (BE+FE). Badge label в конфиге может оставлять pictograph.
10. **Инсайты / подсказки** (если есть): факт → гипотеза → действие; без недоказуемых «мы увидели X».
11. **Письма / тикеты** — не обещать delivery (email/push), пока канал не в DoD; UI-рубильник ≠ факт доставки.

## Антипаттерны

- Жаргон домена / ops на первом экране без перевода.
- Обещание результата / «гарантия» без evidence.
- «Полный доступ всем после регистрации», если free = teaser.
- Ops-слова и сырые enum’ы из правой колонки словаря в owner UI.
- Ведущие emoji в заголовках primary / teaser / публичном превью.
- Инструкции разработчика в UI.
- Второй файл «voice/vision» в чате или соседнем доке — править **здесь**.
