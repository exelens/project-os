# Вес workflow (сколько церемонии)

Не каждый запрос = полный Prism. Выбери уровень по риску и этапу (`stages.md`).

## Уровни

| Уровень | Когда | Что делать | Чего не делать |
|---------|--------|------------|----------------|
| **L0 — post-code** | Мелкая правка, известный контур, есть тест рядом | Post-code loop из `AGENTS.md` (тесты → docs → тесты) | Не открывать `reviews/`, не звать 01–08 |
| **L1 — стой** | Между закрытыми Prism-циклами; короткая FIX-волна; «что-то болит», но не релиз | [`../prism/pisdetscheck.md`](../prism/pisdetscheck.md) → Disposition → точечный FIX | Не merge в `B-*`; не новый полный цикл «ради третьей сети» |
| **L2 — light Prism** | Смена контракта в одном слое; серая зона в 1–2 областях | 1–2 audit-слоя + partial 07 + wave + **08 с evidence** | Не гонять все 01–06 «на всякий случай» |
| **L3 — full Prism** | Крупный релиз, смена публичного контракта, много серых мест, недоверие к CI | Полный цикл [`../prism/README.md`](../prism/README.md) | Не заменять зелёным CI; не wipe `reviews/` агентом |

## Быстрый score (0–8)

Сложи баллы; уровень = max подходящий.

| Фактор | +0 | +1 | +2 |
|--------|----|----|-----|
| Этап (`stages.md`) | Spike, ломать можно | Closed/Open Beta | Prod / деньги |
| Blast radius | 1 файл / 1 модуль | Несколько модулей | Публичный API / данные / auth |
| Тесты на контур | Есть и зелёные | Тонкие / flaky | Нет / `assert True` рядом |
| Контракт наружу | Не трогаем | Внутренний | HTTP/HTML/copy пользователю |

| Сумма | Уровень |
|-------|---------|
| 0–2 | L0 |
| 3–4 | L1 (если есть незакрытая боль / межцикл) иначе L0 |
| 5–6 | L2 |
| 7–8 | L3 |

При сомнении — на уровень ниже + явный инвариант в PR/чате, а не «полный аудит из страха».
